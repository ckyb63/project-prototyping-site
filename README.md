# PulsePatch Concept Site

Presentation website and product documentation for **PulsePatch** - a stick-on emergency response patch concept for CPR guidance during suspected cardiac emergencies.

## What is in this repo

- `index.html` - main GitHub Pages presentation site
- `documents/PulsePatch_PRD_Professional.pdf` - polished PRD for sharing
- `support/Support Doc/PulsePatch_PRD_Professional.tex` - LaTeX source for PRD
- `i18n.js` + `locales/` - client-side language switcher and translations

## Language support

The site supports:

- English (`en`)
- Traditional Chinese (`zh-Hant`)
- Hindi (`hi`)

Switch language from the header language toggle. The selected language is saved in `localStorage`.
