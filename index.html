PulsePatch is a stick-on emergency response patch designed to help bystanders act fast during sudden cardiac arrest by giving real-time CPR guidance and compression feedback.

Why this matters

There is a critical gap between collapse and effective intervention. PulsePatch aims to reduce hesitation, improve CPR quality, and buy time until EMS or AED support arrives.

The Problem

Survival outcomes in sudden cardiac arrest depend on immediate and correct bystander action, but panic and uncertainty often delay or reduce CPR quality.

Delayed response

Many bystanders hesitate before taking action in high-stress emergencies.

Technique errors

Common CPR mistakes include poor rhythm, inconsistent compressions, or no compressions.

Guidance gap

AEDs are not always immediately available, and existing monitors do not actively coach intervention.

The PulsePatch Solution

A zero-friction adhesive patch that transitions from detection to active CPR guidance in seconds.

How it works

  • Stick patch on the chest and auto-activate.
  • Capture ECG and motion signals (IMU-based detection).
  • Trigger coaching mode when no response is detected.
  • Guide compression pace and consistency with real-time feedback.

Core feature set

Adhesive chest patch ECG + IMU sensing CPR BPM feedback Metronome + visual cues Two-minute reassessment cycle Future BLE + app integration

Development Roadmap

Execution plan from prototype to regulatory pathway and pilot validation.

Phase 1 (0-3 months)
IMU-based compression detection, metronome + LED feedback, basic patch form factor.
Phase 2 (3-6 months)
ECG integration, state detection logic, improved UX and enclosure design.
Phase 3 (6-12 months)
CPR mannequin testing, controlled user studies, iterative feedback optimization.
Phase 4 (12+ months)
Clinical trials, FDA submission, certification workflow.
