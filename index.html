What this page is doing

Everything below runs in your browser from static files. No server compute. No build step. Just HTML, CSS, and JS pushing APIs that GitHub Pages happily hosts.

  • Canvas 2D field — thousands of agents reacting to pointer velocity
  • Web Audio — arm/disarm anytime; drone shifts with scroll and mode
  • Scroll theater — each section rewires the field’s behavior
  • Keyboard as instrument — letters spawn, decay, and color the mesh
  • Pointer + touch — no drag-and-drop; works on phone and desktop
